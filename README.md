# GEDRA | Topografía
### Construcción con Precisión

Sistema avanzado de ingeniería topográfica diseñado para el cálculo y compensación de poligonales cerradas. Optimizado para su uso en campo mediante dispositivos móviles.

## 🛠️ Funcionalidades
* **Gestión de Obra:** Sistema de creación y administración de proyectos.
* **Cálculo de Poligonales:** Compensación angular y lineal (Método de la Brújula).
* **Visualización en Tiempo Real:** Generación de croquis dinámicos mediante `Chart.js`.
* **Reportes Técnicos:** Cartera de cálculo detallada con rumbos, azimuts y coordenadas.
* **Auditoría IA:** Análisis automático de precisión para dictaminar la validez del levantamiento.

## 📂 Instalación
1. Descarga este repositorio.
2. Asegúrate de que el archivo `image_4da43f.jpg` esté en la misma carpeta que el `index.html`.
3. Abre `index.html` en cualquier navegador o actívalo mediante **GitHub Pages**.
